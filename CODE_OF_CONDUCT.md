# Code of Conduct

## Our pledge

Everyone participating in this project - issues, PRs, discussions - keeps the space professional and respectful.

## Standards

**Good:** technical critique grounded in evidence; failure reports with transcripts; patient explanation of reasoning; welcoming questions.

**Bad:** harassment or personal attacks; hostile gatekeeping; spam, astroturfing, or AI-generated noise PRs with no human review; promoting tools that violate others' security or privacy.

## Enforcement

Violations in issues/PRs get one warning, then a block. Report problems via an issue marked `conduct` or a private GitHub message to a maintainer.

This project is MIT-licensed volunteer work. Be kind to the volunteers.
