House rules for research docs (see [CONTRIBUTING.md](../CONTRIBUTING.md)):

1. Every skill rule that changes agent behavior cites reasoning here or in its PR.
2. Claims about model behavior reference published work or reproducible observation, not vibes.
3. Procedural countermeasures over judgment demands - we instruct process, not capability.
